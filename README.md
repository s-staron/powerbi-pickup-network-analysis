# Pickup Network Analysis (Power BI)

Portfolio project: a Power BI report for the head of the pickup-point network of a fictional parcel carrier, **Norvane Parcel**.

> **All data in this repository is synthetic.** It is produced by a seeded Python script (`scripts/generate_data.py`). Norvane Parcel, its points, regions and numbers are invented.

Work in progress. Full documentation follows in `docs/`.
